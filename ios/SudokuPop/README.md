# Sudoku Pop iOS

SwiftUI iOS version of the Android Sudoku Pop game.

Open `SudokuPop.xcodeproj` in Xcode and run the `SudokuPop` scheme on an iPhone simulator or device.

## Matched Android Features

- Splash, welcome, difficulty selection, game, leaderboard, and settings screens.
- Modern Pop and Vibrant Night themes.
- Chinese Simplified, Chinese Traditional, English, and Japanese labels.
- Unique-solution puzzle generation with the same difficulty givens ranges.
- Notes, auto notes, hints, undo, erase, same-row/column/box highlighting, same-value highlighting, and error limits.
- Best-time leaderboard persisted with `UserDefaults`.

## Requirements

- Xcode 15 or newer.
- iOS 17 or newer target, because the app uses Swift Observation.
